Quick Installation Guide

Follow these 3 simple steps to set up OmniDial on your Android device.

1

Download & Install APK

Download the APK file directly to your phone. Tap the downloaded file in your notifications or Downloads folder to begin installation. Allow "Install unknown apps" if prompted.

2

Set as Default Phone App

Open OmniDial. When prompted, tap "Set as Default" to enable complete call handling, spam call detection, and lock-screen incoming call controls.

3

Grant Telephony & Contacts Permissions

Accept the requested Android permissions (Contacts, Phone Calls, Call Log) so OmniDial can display your contacts and manage calls seamlessly.
