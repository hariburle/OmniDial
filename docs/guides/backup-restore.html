Backup & Restore

One tap saves your rules, favorites, speed dials, and settings. Move to a new phone without rebuilding anything.

Steps

  2. What's inside a backup

Back up now

Backup Now
Settings → Backup → Backup Now.

Open Settings, find the Backup section, and tap Backup Now. That's the whole process — no folder picking, no account sign-in.

The backup is saved to your Documents/OmniDial/ folder, so it survives even if you uninstall the app.

2

What's inside a backup

  • Automation rules — every caller rule, exactly as configured.
  • Favorites grid — your VIPs, their numbers, and your custom card order.
  • Speed dials — your 2–9 key assignments.
  • Settings — SIM modes and per-number SIM choices, spam filters, channel preferences, appearance.
  • Annotated calls — call history entries that have your notes, callback reminders, or spam markings. Plain call records are skipped to keep backups small (your phone's system call log already keeps those).
Integrity: every backup carries a SHA-256 checksum, so a corrupted file is caught before it can overwrite your good data. Restores run transactionally with live progress, so you always know what's happening and never end up half-restored.

Browse Files — import from another device
Pick a backup, or browse for one.

Same phone: open Settings → Backup and tap any backup in the list to restore it instantly.

New phone: install OmniDial, copy a backup file from your old phone (or cloud drive) and use Browse Files to import it. Your whole setup — rules, favorites, speed dials — lands exactly as it was.

Make it a habit: back up before reorganizing favorites or experimenting with rules. Restore is just as fast as backup.
