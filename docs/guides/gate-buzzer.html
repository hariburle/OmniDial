Set Up a Gate Buzzer Rule

When your apartment intercom calls, OmniDial can answer it, key in the door code, and hang up — all automatically, even if your phone is in your pocket.

Steps

  1. Open the Recipes gallery
  2. Pick the Apartment Gate Buzzer template
  3. Enter your intercom's number
  4. Check the door code
  5. Test it safely, then save
  6. What happens on a real call
1

Open the Recipes gallery

Open the Rules tab (the 🤖 icon in the bottom bar) and tap the Recipes button at the top. Recipes are ready-made automation templates — you don't have to build the rule from scratch.

2

Pick the Apartment Gate Buzzer template

Choose Apartment Gate Buzzer.

Tap Apartment Gate Buzzer. This loads a rule that: answers after 1 second → sends the 9# unlock tone → hangs up after 2 seconds. All timings are adjustable.

Type the number your intercom calls from.

The rule needs to know which incoming number is your intercom. Type the number the gate calls from — you can find it in Recents after a visitor buzzes you once.

Tip: if your building has two gates with different numbers, duplicate the rule (one-tap clone) and change the number on the copy.

Match the door code to your building's.

The template sends 9#, which works for most buildings. If yours uses a different code (like *#), change it here. During the tone the mic auto-mutes so the beeps come through cleanly.

5

Test it safely, then save

Before going live, run the dry-run simulator in the rule editor — it walks through each step (answer → wait → send code → hang up) without placing any real call, so you can verify the timing feels right.

Going further: in the rule editor you can also restrict the rule to only run on your home Wi-Fi, or get a text confirmation after the door opens. Both are optional.

Tap Save and make sure the rule's toggle is on.

6

What happens on a real call

Next time a visitor buzzes you: your phone answers after 1 second, keys in 9#, and hangs up after 2 seconds. You can watch it happen in the call screen, or ignore your phone entirely — the door just opens. Every trigger is logged under the History icon in the Rules tab, so you can always check what ran.

Note: for the rule to answer calls, OmniDial must be your default phone app and have phone permissions granted.
